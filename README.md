# Kei Theme

A clean and minimal Visual Studio Code light color theme.

## Screenshots

![Kei Theme Preview](screenshot.png)

## Installation

1. Open **Extensions** in VS Code (`Ctrl+Shift+X`)
2. Search for **Kei theme**
3. Click **Install**
4. Open the Command Palette (`Ctrl+Shift+P`) → **Preferences: Color Theme** → select **Kei**

Or install manually via VSIX:

1. Download `kei-theme-0.0.1.vsix`
2. Extensions sidebar → `···` → **Install from VSIX...**
3. Select the downloaded file

## Features

- Light theme with clean, easy-on-the-eyes contrast
- Carefully selected syntax colors for readability
- Minimal UI chrome — lets your code take center stage
